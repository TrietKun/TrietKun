Bá Toán 11

Grade 11 maths for students who lost the basics

📚 Store app 📱 iOS 🔒 Source private

OVERVIEW

A Flutter app that teaches Grade 11 maths. It is built for students who lost the basics in earlier years and need to catch up while keeping pace with the current syllabus.

THE PROBLEM

Grade 11 maths builds on earlier grades, so a student with gaps stops following the lesson at the first step that needs old knowledge. Bá Toán 11 shows that older knowledge at the top of each lesson and lets the student relearn it before moving on.

KEY FEATURES

  • Every lesson lists the older knowledge it relies on, each with a relearn button
  • Illustrated lectures that explain a concept with a picture first, such as directed angles on a Ferris wheel
  • Concept callouts and short activities inside the lecture text

MindForge

Train your brain: 24 cognitive mini-games

🧠 Open Source 🎮 Flutter + Flame 🌐 VI / EN

OVERVIEW

A brain-training app packing 24 short, animated cognitive games into seven categories: speed, memory, attention, flexibility, problem solving, math and language. Every game ships a first-time bilingual tutorial, a difficulty and play-time selector, and per-game FX. A daily challenge picks a deterministic game and score target each day, all wrapped in a vibrant dark "aurora" design system with a per-game accent color. Built feature-first with a shared widget kit, the Flame engine for reflex games, and a custom in-memory i18n layer (Vietnamese / English) that rebuilds the whole tree on language switch.

THE PROBLEM

Cognitive practice gets stale when it is one repeated drill. MindForge spreads it over 24 short games in seven categories, and a daily challenge picks the game and the score target for you.

KEY FEATURES

  • 24 mini-games across 7 cognitive categories with a unified session model
  • Per-game first-time tutorial (bilingual, persisted) + in-game replay button
  • Daily challenge: deterministic game + score target every day
  • Difficulty (Easy / Normal / Hard) and play-time selectors applied globally
  • Flame-powered reflex games + flutter_animate entrances and per-game FX
  • Live aurora background with per-game accent theming
  • Full bilingual UI (Vietnamese default / English) switchable in-app
  • Sound kit with tuned per-event volumes via audioplayers

TECH STACK

Flutter Dart Flame flutter_animate Material 3 SharedPreferences audioplayers Custom i18n Feature-first arch

Lịch Việt

Offline Vietnamese lunar calendar

📅 Open Source 📱 iOS + Android 🌐 VI / EN

OVERVIEW

A Vietnamese lunar calendar with a holiday countdown. Every calculation runs on the device, with no network calls, accounts or backend.

THE PROBLEM

Vietnamese households check the lunar calendar every week for anniversaries, the first and fifteenth of the lunar month and the holiday schedule. Most apps fetch that data from an API, so losing signal means losing the calendar. Lịch Việt computes it locally. The lunar engine is written from scratch in pure Dart.

KEY FEATURES

  • Solar to lunar conversion, sexagenary cycle, solar terms and auspicious hours, all against UTC+7
  • Events that repeat every lunar year and resolve to the right solar date, with local notifications
  • Leave planner that combines annual leave with public holidays to find the longest break
  • Leave request composer that exports an A4 PDF
  • Overseas mode: local time on screen, lunar maths anchored to Vietnam

TECH STACK

Flutter Dart Riverpod go_router Drift / SQLite Local notifications
