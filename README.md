# Truong Binh Triet

Mobile Developer · Flutter, based in Ho Chi Minh City, Vietnam.

I build Flutter apps together with the small backends and tools around them, and I like to get the details right before something ships. I use native Android (Kotlin) when a device calls for it. I work in small steps, keep state predictable, and put a working version in front of real users early.

At Workflow (since 10/2025) I work on the customer mobile app for a booking and coworking platform, an Android TV digital signage and screen casting app, and the web booking site and landing pages for a booking chain. Before that I interned at DevStation and Digital for Life.

Portfolio: https://trietkun.github.io/TrietKun/
